# 6T CMOS SRAM Cell

## Project Overview

Design and verification of a 6-transistor (6T) CMOS SRAM cell using the SKY130 130 nm CMOS process.

The goal of this project is to investigate SRAM memory-cell design, transistor sizing, read/write operation, stability, process variation, and physical layout.

## Project Goals

* Design a transistor-level 6T SRAM cell
* Simulate hold, read, and write operation
* Optimize transistor sizing
* Analyze Static Noise Margin (SNM)
* Perform PVT analysis
* Perform Monte Carlo variation analysis
* Create a full-custom physical layout
* Perform DRC/LVS verification
* Extract parasitics
* Compare pre-layout and post-layout performance
